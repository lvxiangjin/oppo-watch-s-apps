# Outcome

对《旋钮炮塔》（OPPO Watch S 圆屏表盘肉鸽塔防，单文件实现于 `游戏/旋钮炮塔/src/main/index.ux`）做一次重点玩法升级并实现交付。核心循环不变（表冠瞄准 → 自动开火 → 清关三选一 → 下一波），在四个方向上加深：

1. **构建深度**：升级槽位上限（持有 6 种不同升级后，三选一只出已持有项的强化）、5 条清关自动进化配方、升级界面长按重抽（每局 2 次）。依据：幸存者类（VS/Brotato/20MTD）调研——窄槽位 + 少而强配方 + 池干预权是 build 身份感的来源。
2. **操作深度**：长按蓄力超载炮（蓄力越久伤害越高，超蓄过热惩罚）、单击锁定目标（磁吸增强）、贴脸击杀奖励（距中心近时分数与充能加倍）。依据：单输入游戏调研（Poinpy 蓄力、Downwell 风险回报、Can't Stop 推贪）。
3. **内容厚度**：3 种行为 Boss 每 5 波轮换（均带前摇预警）、每 3 波阵型波（环阵/斜列/快袭）、第 8 波起精英怪变体、HUD 显示剩余敌人与点状血条、受击红晕/命中白闪/Boss 预警横幅。
4. **长线目标**：击杀/Boss 里程碑解锁永久小强化（开局生效，存档兼容）、菜单上滑进入每日种子挑战（固定当日波次与卡池序列，记录当日最佳）、菜单下滑进入成就页（修复现有无入口死代码）。

交付物：升级后的可玩游戏（源码）、同步的 README 与《游戏设计》文档、通过 `gx build -d oppo-rtos-watch -f` 的构建产物。

# Non-goals

- 不改变核心操作方式：旋转表冠 + 触屏手势；不在屏幕上渲染任何按钮控件（hint 用纯文字提示）
- 不突破平台硬约束：25fps（40ms tick）不变；同屏绘制预算不变（敌人 12 / 己方弹 16 / 敌弹 14 / 粒子 8 / 环 2）；无 canvas
- 不引入工具链/依赖变更（仍为 gx 单包构建，无 npm 依赖）
- 不做数值的全盘重调（在现有数值基线上增量，仅对新系统定数值）
- 不做多语言

# Acceptance examples

- A1 槽位收窄：局内持有 6 种不同升级后，再次清关的三选一只出现已持有升级（描述为等级/强化），不出现新种类
- A2 进化配方：持有配方组件且组件达到要求等级（如超频 3 级 + 暴击）时清关，自动进化并出现进化横幅；进化效果在后续战斗中生效；同一配方不重复进化
- A3 重抽：升级界面长按可重抽当前三张卡，每局限 2 次，界面文字提示剩余次数；用尽后长按无效果
- A4 蓄力超载：战斗中长按开始蓄力、松手沿当前瞄准角释放扇形重弹，伤害/弹数随蓄力时长提升；按住超过蓄力上限触发过热（强制低效释放 + 超载冷却，冷却期间长按无效）
- A5 单击锁定：战斗中单击立即锁定最近敌人（出现锁定环，磁吸窗口与吸附速度提升），再次单击切换到次近目标；480ms 内的第二击仍触发大招
- A6 贴脸奖励：敌人与中心距离 <90px 时被击杀，得分与充能获取翻倍
- A7 Boss 轮换：第 5/10/15… 波出现 3 种 Boss（堡垒环形弹幕+召唤 / 冲刺蓄力突进 / 分裂死亡分裂）之一并按波次轮换，释放强技能前均有可辨识前摇（闪烁或预警）
- A8 阵型波：非 Boss 波每 3 波为阵型波，波次开始前横幅提示，敌人按阵型（环形同圈 / 斜列扇形 / 快袭连发）进场
- A9 精英怪：第 8 波起普通怪概率精英化：HP×3、金色描边、分数×3、击杀额外获得充能
- A10 战斗信息与反馈：HUD 显示剩余敌人数与 HP 点状血条；玩家受击出现红晕反馈，命中敌人出现白闪；Boss 波开始有预警横幅
- A11 局外里程碑：总击杀 200/500/1000 与 Boss 击杀 3 达成后，各自解锁永久强化并在新局生效；旧存档加载后不丢字段、功能正常
- A12 每日挑战：主菜单上滑进入每日挑战，使用当日日期派生种子（不同日期序列不同，同日重开序列相同），结算记录当日最佳波数并在菜单可见
- A13 成就入口：主菜单下滑进入成就页，正确展示成就达成状态，可返回菜单；原有成就数据不丢失
- A14 性能预算不突破：全部新元素绘制受既有上限约束（敌 12/弹 16/敌弹 14/粒子 8/环 2），tick 仍为 40ms
- A15 构建通过：`gx build -d oppo-rtos-watch -f` 构建成功产出 bundle.pkg

# Constraints and invariants

- 输入面只有：wheel（表冠，限幅 ±1.5×0.02）、触摸手势（单击/双击 480ms 判定/长按/上滑/下滑）、实体键兜底（Power/Enter/空格 = 大招）。新交互全部在此面内实现，UI 不渲染按钮
- 渲染面：div + 每帧 style 字符串重建；圆角必须写 CSS 类；466×466 圆屏，中心 (233,233)；HUD 信息放上下弧区
- 存档：@system.storage 单 key；新字段必须经 defaultSave 合并兼容旧档（旧档缺字段自动补默认值）
- 瞄准磁吸基线 ±0.20rad/22% 每帧保留；锁定状态在此基础上增强（窗口 0.30rad、吸附×2），不代打
- 蓄力超载炮期间自动开火不中断（风险体现在过热惩罚与时机选择，不在火力空窗）

# Decisions

- 交付边界：方案确认后直接实现进游戏（用户选定）
- 方向取舍：A 构建深度 + B 操作深度 + C 内容厚度 + D 长线目标 全选；表现力反馈默认随包附带（用户选定）
- 调研结论作为设计依据：窄槽位+进化配方+重抽替代商店经济；蓄力+风险条作为触屏深度来源；保留双击大招但主推长按+实体键（双击在手表上易误触，作次级路径保留）
- 双击判定窗口维持 480ms 不动；单击锁定即时生效，与双击共存（第二击仍可触发大招）
- 超载炮与原长按大招冲突的处理：战斗中长按语义改为蓄力超载炮；大招保留在双击与实体键
- 不采用 Supervisor 分解：四个方向全部落在同一 index.ux 强耦合区域，拆分只会增加协调成本（依据 clarification 分解预检标准）
