# capability: combat-controls（战斗操作与反馈）

表冠瞄准 + 触屏手势的战斗操作，以及战斗反馈表现。全部交互不渲染按钮，手势提示用纯文字。

## 输入映射（play 模式）

| 输入 | 行为 |
|---|---|
| 旋转表冠 | 瞄准（不变，限幅与灵敏度同现状） |
| 单击 | 锁定目标（即时生效，见下） |
| 480ms 内第二击 | 大招（保留现状判定窗口） |
| 长按 | 蓄力超载炮（原"长按大招"语义移除） |
| 实体键 Power/Enter/空格 | 大招兜底（不变） |
| 双击 | 大招（不变） |

菜单/升级/结算等非战斗界面的单击确认行为不变；菜单新增上滑/下滑（见 meta-progression spec）。

## 蓄力超载炮

- 长按 ≥250ms 进入蓄力：charge 从 0 线性增长至 1（速率 0.9/s），炮塔处显示蓄力条（复用现大招充能条位置，独立颜色）。
- 松手释放：沿当前瞄准角 ±0.35rad 扇形发射 `5 + round(4 × charge)` 发重弹；每发伤害 `2 + 2 × charge`（享受 dmgAdd 与暴击加成），弹速 6，固定穿透 1。
- charge < 0.25 时松手仍释放最小扇形（5 发、伤害 2）。
- 过热：charge 到 1 后继续按住 0.45s 触发过热——强制以 charge=0.3 释放，并进入 2.5s 冷却；冷却期间长按无效，蓄力条显示冷却进度。
- 蓄力/冷却期间自动开火不中断；蓄力中松手前切换波次（清关）则取消蓄力不释放。
- 蓄力条与既有大招充能条互不替代：大招充能仍按击杀累计。

## 单击锁定目标

- 战斗中单击：按"敌人与中心距离"排序锁定最近者；已处于锁定状态时单击切换到次近目标，循环。
- 锁定表现：目标外圈白色锁定环（sprite 绘制）。
- 锁定增强磁吸：吸附窗口 0.20→0.30rad，吸附速度系数 ×2；未锁定时保持基线磁吸。
- 锁定目标死亡时自动转移到剩余最近目标；敌人清空则解除锁定。
- 单击即时生效，不等双击判定窗口；480ms 内出现第二击时照常触发大招、锁定不变。

## 贴脸风险回报

- 敌人被击杀时与中心距离 < 90px：得分 ×2、大招充能 +0.10（普通击杀 +0.05）。
- 伴随金色粒子爆发强化感知；无新增文字元素。

## 战斗反馈（默认随包表现力）

- 受击红晕：玩家受击时屏幕边缘红晕一闪（约 300ms 的 overlay 显隐）。
- 命中白闪：被击中的敌人边框短暂变白（约 0.1s）。
- Boss 预警：Boss 波开始横幅显示 `BOSS INCOMING`（替代原 `BOSS` 文案）。
- HUD：HP 行由数字改为点状血条（● 字符）；新增 `ENEMIES n` 行显示剩余敌人（场上 + 待生成）。
- HUD 布局收敛至圆屏上下弧区，不新增交互元素。
