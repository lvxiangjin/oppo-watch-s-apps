# capability: meta-progression（长线目标与局外系统）

局外里程碑、每日种子挑战、成就入口与存档兼容。数据存 `@system.storage` 现有单 key。

## 局外里程碑（4 条）

达成后永久生效于之后所有新局，菜单副标题行展示已达成数量：

| 里程碑 | 条件 | 永久强化 |
|---|---|---|
| 强健体魄 | 总击杀 ≥ 200 | 开局生命上限 6（初始 5） |
| 蓄能核心 | 总击杀 ≥ 500 | 开局大招充能 20% |
| 战术储备 | 总击杀 ≥ 1000 | 每局重抽次数 +1（2→3） |
| 老兵光环 | Boss 击杀 ≥ 3 | 开局随机获得 1 级随机升级 |

- 达成判定复用现有成就检查时点（击杀/Boss 击杀落档后）；达成时 toast 提示。
- 强化在 `startRun` 时应用；存档新增字段对旧档自动补默认值（`Object.assign(defaultSave(), 旧档)` 深度合并）。

## 每日种子挑战

- 主菜单**上滑**（垂直位移超过 40px 的向上滑动）进入每日挑战局：
  - 种子由当日日期派生（如 `YYYYMMDD` 数值经 mulberry32 初始化）。
  - 波次敌人生成、阵型选择、精英概率、三选一抽卡、重抽结果全部走种子随机序列——同日多次挑战序列相同，不同日期序列不同。
  - 普通局维持真随机，不受影响。
- 每日挑战结算：当日最佳波数写入存档（仅更高时覆盖），菜单副标题行显示 `每日最佳 WAVE n`；跨日自动作废旧记录按日期比对。
- 结算页以 `每日挑战` 标识区分普通局。

## 成就入口（修复）

- 主菜单**下滑**（垂直位移超过 40px 的向下滑动）进入成就页（激活现有 `openAch`/`closeAch` 逻辑）。
- 成就页列出全部成就的达成状态（✓/○），单击返回菜单；原有成就数据不丢失。
- 菜单 hint 文字同步更新（如 `单击开始 · 上滑每日 · 下滑成就`），不渲染按钮。

## 存档兼容

- 新增字段：里程碑标记、每日挑战记录；读取旧档时缺失字段补默认值，旧字段（bestWave/kills/runs/ultUses/bossKills/weapons/ach）语义不变。
- 写档时机与现状一致（关键事件后立即落档）。
