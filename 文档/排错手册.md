# 排错手册

按"现象 → 原因 → 处理"整理。全部来自真机实测。

---

## 安装

### `5005 invalid package`

**原因**：`manifest.json` 缺 `icon` 字段，或包容器损坏。

```json
{
  "icon": "/assets/icon.png"
}
```

真机强制校验 `icon`，模拟器不校验——**模拟器能跑不代表能装**。

### `5001 The package was not found`

启动时报这个，说明包没装上，或包名拼错。

- 用「安装应用」的返回码判断是否装成功（`code:200`）
- 「检查安装」接口语义不可靠，不要用它判断

### 瑰元助手「下载」里看不到刚 push 的包

少了媒体扫描：

```bash
adb shell am broadcast -a android.intent.action.MEDIA_SCANNER_SCAN_FILE \
  -d file:///sdcard/Download/xxx.rpk
```

或者直接用 `工具/ows.py install`。

### 手机上装不了瑰元助手

APK 来自 <https://www.pgyer.com/glyphix-assistant>。安装时可能需要允许"安装未知来源应用"。

### 侧载后桌面入口错乱（点微信打开别的应用）

**原因**：调试通道安装后，桌面的入口映射没有刷新。

**处理**：**重启手表**。

如果重启后仍错乱：

1. 安装 [`清理工具`](../应用/清理工具/)，把侧载包全部移除
2. 重启
3. 确认系统应用恢复后，再决定是否重装

### 商店装「敲木鱼」失败

**原因**：侧载的 PurrLaunch 占用了 `com.xfaith.woodenfish`，签名与商店包不一致。

**处理**：卸载该包（`cleanup` 里把 `com.xfaith.woodenfish` 加进列表），再从商店安装。

## 渲染

### 真机画面全黑，只有 HUD 文字

**原因**：真机不支持 canvas。`getContext('2d')` 拿不到可用上下文，绘制调用全部无效。

**处理**：改用 div 渲染。参考 [`旋钮炮塔`](../游戏/旋钮炮塔/)：

- 背景 / 雷达圈：静态 div + `border-radius: 50%`
- 动态元素：一个 `sprites` 数组，每帧生成 `style` 字符串
- 圆点用 CSS 类 `border-radius: 50%`，行内只写 left/top/width/height/background-color

### 元素全是方块，圆角不生效

**原因**：行内 `style` 不支持 `border-radius`（报 `unknown style property: borderRadius`）。

**处理**：把 `border-radius: 50%` 写到 CSS 类里，行内只放位置和颜色。

### 圆环画不出来

**原因**：行内 `border` 也不生效。

**处理**：用两层圆拼：外层实心彩色圆 + 内层背景色圆（半径小 3px）。

### `transform: rotate()` 无效

**原因**：真机忽略该属性。

**处理**：自己算坐标。炮塔朝向用一串沿角度分布的圆点模拟。

### 动态 class 不生效

**原因**：真机不支持动态 class 绑定。

**处理**：用两个带静态 class 的元素 + `if` 切换。

## 输入

### 屏幕点不动

**原因**：只有**有实底色**的元素能命中触摸；透明元素收不到事件。

**处理**：

- 覆盖层加 `background-color`
- 世界层用不透明背景
- 点击同时挂在多层，用时间戳去重（本项目用 80ms）

### `on:click` 不触发

**原因**：部分场景下真机只派发 touch 事件。

**处理**：改用 `on:touchend`。canvas 和 div 的 `touchstart/touchend` 均可。

### 表冠转一格，炮塔转好几圈

**原因**：真机 `deltaY` 的绝对值远大于模拟器。

**处理**：限幅 + 降低系数：

```js
let step = e.deltaY
if (step > 1.5) step = 1.5
if (step < -1.5) step = -1.5
this.angle += step * 0.02
```

并在屏幕边缘画一个瞄准光点，转快了也能看到朝向。

### 表冠按压想当按钮用

真机上按压会以 `on:keydown` 的 `key: 'Power'` 上报。

```html
<div on:keydown="onKey($event)">
```

```js
onKey(e) {
  if (e.key === 'Power') {
    // 做自己的事
    e.stopPropagation()   // 拦截系统默认返回
  }
}
```

> 注意：`stopPropagation` 会阻止系统默认行为（返回表盘/电源菜单），只在真正需要时调用。

## 表盘

### 表盘包装上了，但表盘选择器里没有

**原因**：侧载的表盘包（`type: dial`）能安装，但系统表盘选择器只展示商店/系统签名的表盘。

**处理**：目前无解。表盘包可以作为普通应用被启动（会显示为齿轮图标），但不会进入表盘列表。

### 表盘包卸载后残留记录

Glyphix 框架的已知问题：表盘包卸载不会清理 `ADBT_Dial` 数据库记录。目前没有用户侧修复手段。

## 开发

### 启动就报 `too many reactive properties`

`data` 里绑定的属性太多。减少绑定字段，或把不需要响应式更新的状态放到 `data` 外面。

### 应用装上了，但系统桌面没有入口

OWS 的桌面菜单是硬编码的。第三方应用不会自动获得入口：

- 会以齿轮图标出现在桌面（部分固件）
- 或用 PurrLaunch 占位已有槽位
- 或用「瑰元助手 → 启动应用」直接按包名启动

### 升级安装失败

`versionCode` 没加。覆盖安装必须比已装的大。

## 安全

### rpk 里能看到 API key

构建时注入的 key 会进包。**不要分享、上传或提交构建产物**。仓库的 `.gitignore` 已排除 `*.rpk` / `*.pkg`。

### 瑰元助手要「所有文件访问权限」

它需要读取 `Download` 里的 rpk。授权后可在系统设置里收回。
